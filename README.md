## Le public cible

- Pour qui : famille 10+
- Ce qui est important pour eux : se sentir intelligent et avoir un travaille d'équipê

## La conception

- L'intrigue : T'es dans la masion en version Otherworld de Coraline
- Le nombre d'énigmes : environ 5
- Le type d'énigmes : Trouver une clé, trouver un anomalie dans une chambre
- Les besoins matériels : Des clés, meubles, papiers crayon
- Les besoins technologiques : Machine a vapeur, lumière, speaker
- Les besoins humains : Mère Otherworld
- Le plan des salles (croquis) :

![Plan des salles](plan-salles.jpg)



## Les éléments importants

- Engagement sensoriel : tu peux sentir la nourriture de la cuisine (chandelles), la musique inentisifie lorsque la mere te vois
- Conception spatiale : la maison de Coraline mais en version otherworld.
- Rétroaction : Il y aura des techniciens derrière les murs pour crée les effets de l'expérience. ???
- Technologie invisible : speaker dans les murs, lumière qui change de couleurs. 

## Les risques et la sécurité

- Risque 1 : quelqu'un tombe des escaliers (solution : on va faire qu'il a peu de marches pour moins de risques)
- Risque 2 : un enfant qui tribuche face au monstre (solution : l'actuer poursuit les parents au lieu des enfants)
